# دليل تدريب النموذج على بيانات حقيقية

## 📋 نظرة عامة

هذا الدليل يشرح كيفية تدريب النموذج على بيانات حقيقية من إشارات اليد لجعل النتائج دقيقة.

---

## 🔄 العملية الكاملة

### الخطوة 1: جمع البيانات من التطبيق

1. **شغّل التطبيق** على جهاز Android
2. **افتح صفحة الكاميرا** (Sign to Text)
3. **اعط إشارة** أمام الكاميرا
4. **اكتب اسم الإشارة** (مثل "أ", "ب", "مرحباً")
5. **احفظ الإشارة** (استخدم زر الحفظ)
6. **كرر العملية** لعدة إشارات:
   - **لكل حرف**: 50-100 عينة (مثلاً: 50 مرة لحرف "أ")
   - **لكل كلمة**: 100-200 عينة (مثلاً: 100 مرة لكلمة "مرحباً")

**ملاحظة مهمة:**
- كلما زادت العينات، كانت النتائج أفضل
- حاول التنويع في:
  - زاوية اليد
  - المسافة من الكاميرا
  - الإضاءة
  - وضع اليد

---

### الخطوة 2: استخراج ملف CSV

بعد جمع البيانات، يجب استخراج ملف CSV من التطبيق:

#### الطريقة 1: استخدام ADB (Android Debug Bridge)

```bash
# ابحث عن الملف
adb shell "run-as com.example.handspeak find /data/data/com.example.handspeak/files -name '*.csv'"

# انسخ الملف
adb pull /data/data/com.example.handspeak/files/training_data/user_training_data.csv scripts/
```

#### الطريقة 2: استخدام Android Studio

1. افتح **Device File Explorer** في Android Studio
2. اذهب إلى: `/data/data/com.example.handspeak/files/training_data/`
3. انسخ ملف `user_training_data.csv`
4. الصقه في مجلد `scripts/`

#### الطريقة 3: إضافة زر تصدير في التطبيق (اختياري)

يمكن إضافة زر في الإعدادات لتصدير الملف مباشرة.

---

### الخطوة 3: تدريب النموذج

1. **افتح Terminal** في مجلد `scripts/`

2. **تأكد من تثبيت المكتبات المطلوبة:**
   ```bash
   pip install tensorflow==2.16.1 pandas scikit-learn numpy
   ```

3. **شغّل سكريبت التدريب:**
   ```bash
   python train_model.py
   ```

4. **اتبع التعليمات:**
   - أدخل مسار ملف CSV (أو اضغط Enter للبحث في `scripts/`)
   - أدخل عدد الـ epochs (افتراضي: 50)
   - أدخل حجم الـ batch (افتراضي: 32)

5. **انتظر حتى ينتهي التدريب**

---

### الخطوة 4: استخدام النموذج المدرب

بعد انتهاء التدريب:

1. **في Android Studio:**
   ```
   Build > Clean Project
   Build > Rebuild Project
   ```

2. **شغّل التطبيق** واختبر النموذج

---

## 📊 متطلبات البيانات

للحصول على نتائج جيدة:

| نوع الإشارة | عدد العينات الموصى به |
|------------|---------------------|
| حرف واحد | 50-100 عينة |
| كلمة | 100-200 عينة |
| **إجمالي (28 حرف + 20 كلمة)** | **~3400-4800 عينة** |

**ملاحظة:** يمكن البدء بعدد أقل (مثلاً 10-20 عينة لكل حرف) للاختبار، لكن النتائج ستكون أقل دقة.

---

## 🔧 استكشاف الأخطاء

### المشكلة: "الملف غير موجود"

**الحل:**
- تأكد من جمع البيانات أولاً
- تحقق من مسار الملف
- استخدم ADB لاستخراج الملف

### المشكلة: "عدد العينات قليل"

**الحل:**
- جمع المزيد من البيانات
- ركز على الحروف/الكلمات الأكثر استخداماً أولاً

### المشكلة: "دقة منخفضة بعد التدريب"

**الحل:**
- جمع المزيد من البيانات
- تحسين جودة البيانات (إضاءة أفضل، زوايا متنوعة)
- زيادة عدد الـ epochs
- تعديل بنية النموذج (إضافة طبقات)

---

## 💡 نصائح للحصول على نتائج أفضل

1. **تنويع البيانات:**
   - زوايا مختلفة لليد
   - مسافات مختلفة من الكاميرا
   - إضاءة مختلفة
   - خلفيات مختلفة

2. **جودة البيانات:**
   - تأكد من وضوح اليد في الكاميرا
   - تجنب الحركة الزائدة
   - استخدم إشارات واضحة ومستقرة

3. **التدريب:**
   - استخدم validation split (20%)
   - راقب overfitting
   - جرب hyperparameters مختلفة

---

## 📝 ملاحظات

- النموذج الحالي هو **Dense Neural Network** (مناسب للإشارات الثابتة)
- للإشارات الديناميكية (حركات)، قد تحتاج إلى **LSTM**
- يمكن تحسين النموذج بإضافة:
  - Data augmentation
  - Regularization
  - Batch normalization
